NOTAS IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════

1. El logo proporcionado es vertical (JW arriba, SOLUTIONS abajo). Para la web
   necesitamos versión horizontal para el header. Se propone usar isotipo "JW"
   en header + logo completo en footer, o crear versión horizontal con CSS.

2. Las imágenes de portfolio/testimonios usarán placeholders de Unsplash/
   Placehold.co hasta tener reales. Se marcan claramente como "Ejemplo".

3. El switcher de idioma usa data-lang attributes. Contenido duplicado en ambos
   idiomas dentro del mismo HTML, mostrado/ocultado con CSS class .active-lang.
   Esto evita duplicar archivos y mejora SEO con hreflang.

4. Todos los formularios incluyen validación client-side + mensaje de éxito.
   No requieren backend propio (Formspree/Brevo manejan el envío).

5. El código es 100% responsive: mobile-first, breakpoints 576/768/992/1200px.
