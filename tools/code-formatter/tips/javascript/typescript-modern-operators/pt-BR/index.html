TypeScript moderno: ?., ?? e satisfies sem erros de formatação

Três operadores reduzem o código defensivo: encadeamento opcional ?., coalescência nula ?? e o operador satisfies do TypeScript 4.9+, que valida o tipo sem alar

2026-11-02 · Dicas de Sintaxe · JAVASCRIPT

Dica da semana

Três operadores reduzem o código defensivo: encadeamento opcional ?., coalescência nula ?? e o operador satisfies do TypeScript 4.9+, que valida o tipo sem alargar o valor.

const config = {
  retries: 3,
  endpoint: "https://api.example.com",
} satisfies Record<string, string | number>;

const timeout = options?.timeout ?? 5000;
const city = user?.address?.city ?? "Sin ciudad";

Regras rápidas

  • Use ?? (não ||) quando 0 ou "" são valores válidos.
  • Evite cadeias ?. com mais de três níveis: sinal de um modelo mal projetado.
  • Prefira satisfies a as para não silenciar erros de tipo.
