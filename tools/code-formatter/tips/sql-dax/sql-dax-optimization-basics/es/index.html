En SQL, selecciona solo las columnas necesarias y filtra temprano. En DAX, guarda subresultados en variables (VAR) para evaluarlos una sola vez.

SELECT o.id, o.total, c.name
FROM orders AS o
JOIN customers AS c ON c.id = o.customer_id
WHERE o.created_at >= DATE '2026-01-01'
ORDER BY o.total DESC;

Reglas rápidas

  • Evita SELECT * en producción.
