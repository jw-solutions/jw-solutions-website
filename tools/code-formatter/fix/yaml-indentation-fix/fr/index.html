Comment corriger bad indentation of a mapping entry dans YAML 1.2

YAML utilise l'indentation pour définir la structure : un niveau mal aligné provoque « bad indentation of a mapping entry » ou une erreur d'analyse.

Antes (con error)

servicio:
    nombre: api
  puerto: 8080

Después (corregido)

servicio:
  nombre: api
  puerto: 8080

Cómo solucionarlo

  1. Alignez toutes les clés d'un même niveau avec le même nombre d'espaces.
  2. N'utilisez que des espaces (2 par niveau) : YAML n'accepte pas les tabulations pour l'indentation.
  3. Collez le code dans le formateur : le diagnostic signale la ligne et peut la corriger.
