Como corrigir reached end of file while parsing em Java 21

O javac mostra este erro quando falta uma chaveta de fecho e o compilador chega ao fim do ficheiro sem fechar a classe ou o método.

Antes (con error)

public class Main {
    public static void main(String[] args) {
        System.out.println("Hola");
    }

Después (corregido)

public class Main {
    public static void main(String[] args) {
        System.out.println("Hola");
    }
}

Cómo solucionarlo

  1. Conte as chavetas "{" e "}": a classe e cada método precisam do seu par.
  2. Indente cada bloco; a chaveta em falta costuma estar no fim de um método ou da classe.
  3. Cole o código no formatador: o diagnóstico assinala a linha e pode corrigi-la.
