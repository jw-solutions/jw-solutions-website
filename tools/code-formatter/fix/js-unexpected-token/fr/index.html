Comment corriger SyntaxError: Unexpected token dans Node.js 22

JavaScript lève « Unexpected token » lorsqu'il trouve un symbole à la place d'un autre, presque toujours à cause d'un crochet non fermé ou d'une virgule en trop.

Antes (con error)

const user = {
  name: "Ana",
  roles: ["admin", "dev"
};

Después (corregido)

const user = {
  name: "Ana",
  roles: ["admin", "dev"],
};

Cómo solucionarlo

  1. Vérifiez la ligne signalée et la précédente : cherchez un « ] », « ) » ou « } » manquant.
  2. Assurez-vous que chaque « [ », « ( » et « { » a sa fermeture du même type et que les virgules ne font que séparer les éléments.
  3. Collez le code dans le formateur : le diagnostic signale la ligne et peut la corriger.
