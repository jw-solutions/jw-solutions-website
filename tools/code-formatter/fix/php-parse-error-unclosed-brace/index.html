Cómo solucionar Parse error: Unclosed '{' en PHP 8.3

PHP detiene la ejecución con un Parse error cuando una función, clase o estructura abre una llave «{» que nunca se cierra.

Antes (con error)

<?php
function sumar($a, $b) {
    return $a + $b;

echo sumar(2, 3);

Después (corregido)

<?php
function sumar($a, $b) {
    return $a + $b;
}

echo sumar(2, 3);

Cómo solucionarlo

  1. La línea del error apunta a la llave sin cerrar, no a donde falta el cierre.
  2. Añade la «}» al final del bloque correcto e indenta el código para comprobar la estructura.
  3. Pega el código en el formateador: el diagnóstico marca la línea y puede corregirla.
