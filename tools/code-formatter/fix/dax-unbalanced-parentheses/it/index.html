Come risolvere The syntax for ')' is incorrect in Power BI DAX

Power BI segnala un errore di sintassi quando una misura DAX ha più «(» che «)», frequente con CALCULATE e FILTER annidati.

Antes (con error)

Ventas Totales =
CALCULATE (
  SUM ( Ventas[Importe] ),
  FILTER ( ALL ( Fechas ), Fechas[Anio] = 2024 )

Después (corregido)

Ventas Totales =
CALCULATE (
  SUM ( Ventas[Importe] ),
  FILTER ( ALL ( Fechas ), Fechas[Anio] = 2024 )
)

Cómo solucionarlo

  1. Conta le parentesi di apertura e di chiusura della misura: devono corrispondere una a una.
  2. Formatta la formula con un argomento per riga: la parentesi mancante salta subito all'occhio.
  3. Incolla il codice nel formattatore: la diagnosi segnala la riga e può correggerla.
