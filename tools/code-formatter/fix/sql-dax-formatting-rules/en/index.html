SQL and DAX formatting rules: a quick guide with examples

SQL and DAX are easier to read and debug when each clause sits on its own line and keywords follow one convention.

Antes (con error)

select id,name,sum(total) as t from orders o join clients c on c.id=o.client_id where o.total>100 group by id,name order by t desc

Después (corregido)

SELECT
  id,
  name,
  SUM(total) AS t
FROM orders o
JOIN clients c
  ON c.id = o.client_id
WHERE o.total > 100
GROUP BY id, name
ORDER BY t DESC

Cómo solucionarlo

  1. Write keywords in uppercase (SELECT, FROM, WHERE, CALCULATE) and start each clause on a new line.
  2. Indent columns, JOINs and nested DAX function arguments with 2 or 4 spaces.
  3. Paste the code in the formatter and press "Format": it applies these rules automatically.
